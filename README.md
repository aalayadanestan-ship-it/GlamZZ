# GlamZZ
A feminine luxury-inspired beauty and fashion website built with HTML and CSS, featuring curated dresses, heels, bags, makeup, and watches


### Designed for Dreamers and Beautiful Days ✨

GlamZZ is a feminine, luxury-inspired fashion and beauty website created using HTML and CSS.

The website brings together curated fashion and beauty finds in a soft pink, cream, and gold aesthetic.

## ✨ Features

- 👗 Curated Dresses collection
- 👠 Heels collection
- 👜 Luxury Bags collection
- ⌚ Watches collection
- 💄 Makeup collection
- 🔍 Inspiration search bar
- 💗 Pink, cream & gold luxury-themed design
- 🛍️ Product links to external shopping websites
- 📱 Responsive layout
- ✨ Hover effects and styled product cards
